# ADR-0002: Rust as the implementation language

- **Status:** Accepted
- **Date:** 2026-09-30
- **Deciders:** owner (interview)

## Context

The kernel and userspace need a systems language. The owner is an expert, but the code will mostly be written by AI agents (Claude Code, Codex), so catching mistakes at compile time is worth a lot.

## Decision

Write the kernel and native userspace in **Rust**, on a pinned nightly toolchain.

## Consequences

- Memory and thread safety catch many kernel bug classes at compile time.
- Mature OSDev crates exist (`x86_64`, `limine`, `acpi`, ...).
- Nightly is required (`abi_x86_interrupt`, `build-std`); the toolchain is pinned and bumped deliberately.
- `unsafe` is unavoidable at the hardware boundary and is confined to small modules with `// SAFETY:` comments.

## Alternatives considered

- C: most references, no safety net.
- Zig: smaller ecosystem.
- C++: more complexity, less safety than Rust.
